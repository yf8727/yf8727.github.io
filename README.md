# 杨锋 · 个人主页（软件测试方向）

一个纯静态单页个人网站，按「软件测试实习生」简历重做。无需构建、无依赖，双击 `index.html` 即可查看。

## 目录结构

```
个人网站/
├─ index.html                    # 页面结构（所有文字内容都在这里）
├─ assets/
│  ├─ css/style.css              # 全部样式（配色、排版、响应式）
│  ├─ js/main.js                 # 交互（主题切换、滚动动画、复制邮箱…）
│  ├─ img/favicon.svg            # 站点图标
│  └─ 杨锋-软件测试-简历.pdf       # 供「下载简历」按钮使用
├─ tools/make_avatar.py          # 早期头像处理脚本（当前未使用，留作备用）
├─ screenshots/                  # 预览截图（可删）
└─ README.md
```

## 本地预览

方式一：直接双击 `index.html`（file:// 下功能全部可用）。

方式二：起个本地服务，手机同 Wi-Fi 也能看：

```powershell
cd "个人网站"
python -m http.server 5188
# 浏览器打开 http://127.0.0.1:5188
```

## 已经做好的东西

- **样式**：深色 / 浅色双主题（跟随系统，可手动切换并记住选择），渐变主色，玻璃拟态导航，网格 + 光斑背景
- **首屏**：报告卡片用等宽字体排成「压测报告」样式，数值与变化率分色；下方 5 个工具标签
- **交互**：滚动进度条、导航吸顶 + 当前区块高亮、IntersectionObserver 入场动画、首屏卡片鼠标跟随微倾斜、移动端汉堡菜单
- **适配**：1440 / 1024 / 768 / 500 / 430 逐档调过；小屏把报告卡片的变化率换行显示，工具标签收起
- **兜底**：`prefers-reduced-motion` 关闭动画；`<noscript>` 下内容依然可见；入场动画 1.6s 未触发则强制显示

## 想改的话，改哪里

| 需求 | 位置 |
| --- | --- |
| 换文字、加项目 | `index.html`，搜区块注释 `<!-- ============ 关于我 ============ -->` 等 |
| 改配色 | `assets/css/style.css` 顶部 `:root`（`--accent` `--accent-2` `--grad`）与 `html[data-theme="light"]` |
| 改主色渐变 | `--grad: linear-gradient(120deg, #8b7bff, #5ad8f0)` 一处改全局生效 |
| 改首屏报告卡片 | `index.html` 搜 `class="term"`，`.term__row` 一行一个指标；分值差异色用 `<em>`（蓝色）/`<em class="warn">`（橙色） |
| 改统计数据 | `.stat__num` 的 `data-count` / `data-suffix` / `data-decimals` |
| 换简历 | 覆盖 `assets/杨锋-软件测试-简历.pdf`（文件名保持一致就不用改链接） |
| 改联系方式 | 导航、`.hero__meta`、`#contact` 三处，以及 `about__card` 里的 `dl.info` |

## 上线（三选一，都免费）

1. **GitHub Pages**：新建仓库 → 上传本目录内容 → Settings → Pages → Source 选 `main` / root。仓库名建议 `yf8727.github.io`，地址即 `https://yf8727.github.io`。中文文件名（`杨锋-软件测试-简历.pdf`）会被编码成 `%E6%9D%A8...`，能正常访问；想干净点可重命名为 `resume.pdf` 并同步改链接。
2. **Vercel / Netlify**：拖目录进去即可，自动给 HTTPS 域名。
3. **自己的服务器**：文件丢到 `/var/www/yangfeng`，Nginx 加一段 `server { listen 80; root /var/www/yangfeng; index index.html; }`。

上线后建议再补：项目截图、GitHub 仓库真实链接、域名（可选）。
